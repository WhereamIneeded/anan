# 安安 · Windows 桌面宠物

以真实布偶猫安安为原型的独立桌宠，保留原 Pets 的形象与动作，增加自主日常行为。原 ChatGPT Pets 安安保持不变。

**当前本地源码版本 1.1.0：统一动作对齐与阶段配置，优化转头、睡眠切换和长拖动。** 2026 年 10 月 27 日已完成 Windows x64 本机构建、64 项自动测试及独立目录启动验证；另有 4 项原生 Qt 复核通过。真实桌面体验、多显示器和无 Python 目标电脑仍待验收。详细结果见 [Windows 验收记录](docs/2026-10-27-Windows验收记录.md)。当前本地仍有未提交修改，不代表远端已同步为 1.1.0。

动作使用独立的对齐点、循环方式和切换时间；睡眠明确划分进入、保持、退出阶段。转头从当前画面短过渡，长拖动继续播放走路，重复要求睡觉不会先叫醒；悬停时延后随机行为。保留去绿边、完整低头姿势、双击启动和十六帧挠耳。详见[本次优化说明](docs/动作配置与衔接优化.md)及[启动说明](docs/构建与使用.md)。

普通用户优先下载发布页中的 Windows ZIP，完整解压后双击 `安安.exe`。发布页尚无可下载成品时，可按下文从源码启动或制作成品。

本机构建的 1.1.0 ZIP 位于 `dist/安安-Windows-x64-v1.1.0.zip`，该路径不随 Git 克隆。完整解压后应保留“安安”文件夹中的所有文件；仅复制 EXE 无法保证运行。源码仓库记录代码、素材和构建脚本，成品 ZIP 通过 GitHub Releases 分发；是否已发布以发布页实际附件为准。

## 使用与功能

解压整个成品文件夹，双击 `安安.exe`。成品包含 Python、Qt 和动画，可离线运行。

大小 100～400，默认 220 逻辑像素；悬停注视不跳，单击跳，拖动不误触。随机挠耳、舔爪、哈欠、伸懒腰、环顾、趴睡和仰卧睡；睡觉有进入、保持、翻身和起身过渡。睡眠中点击先起身再跳。支持托盘、安静模式、可选散步、偏好保存与屏幕位置恢复。

## 公司电脑获取最新版

首次执行 `git clone https://github.com/WhereamIneeded/anan.git`，进入仓库；已有克隆先保存本地修改，再执行 `git pull --ff-only`。

已装 Windows x64 Python 3.10 或更新版本的电脑，双击 `启动安安.cmd` 即可；首次自动准备依赖，以后直接启动。支持 pyenv 当前选中的 Python，无需另外安装 `py`。双击 `制作免安装版.cmd` 可测试并打包，完成后自动打开成品文件夹。旧的 `启动.cmd`、`构建.cmd` 仍可使用。

| 使用场景 | 入口 | 所需环境 |
|---|---|---|
| 使用已经打包好的桌宠 | 完整解压成品 ZIP，双击 `安安.exe` | Windows x64，无需安装 Python |
| 从源码运行、修改后立即体验 | `启动安安.cmd` | 已安装 Windows x64 Python 3.10 或更新版本；首次联网准备项目依赖 |
| 从源码重新制作免安装包 | `制作免安装版.cmd` | 同上；自动准备依赖、测试并调用 PyInstaller 打包 |

两个 CMD 是源码项目的现役入口。成品中的 `安安.exe` 不会调用它们。换电脑从完整源码构建时不需要重新联系 AI，也不需要重新生成图片；全部运行素材已在仓库中。尚未安装 Python 的电脑优先使用发布页的成品。

给非技术用户的步骤见 [使用说明.txt](使用说明.txt)。成品 ZIP 无需安装开发工具。`版本.json` 记录源码提交；从源码压缩包构建时会明确标记提交未知。

## GitHub 构建和发布

仓库已配置 `.github/workflows/构建Windows.yml`：主分支推送或手动触发后，GitHub 的 Windows 构建机安装锁定依赖、执行测试、生成 ZIP；主分支成功后创建 Release 并上传 ZIP 与校验文件。该流程是否成功必须以实际运行记录为准。

需要手动运行时：

1. 先确认最新源码、素材、依赖及构建脚本已经提交并推送到 `main`。
2. 在 GitHub 打开仓库的 **Actions**，选择“构建安安桌面版”。
3. 点击 **Run workflow**，选择 `main`，再次点击 **Run workflow**。
4. 等待流程完成；失败时打开对应步骤查看日志，不将失败记录当作已发布。
5. 成功后打开 **Releases**，在对应版本的 **Assets** 中下载“安安-Windows-x64”成品 ZIP 及 `SHA256SUMS.txt`。
6. 核对校验值与包内 `版本.json` 的版本、源码提交；完整解压后双击 `安安.exe`。

GitHub 自动提供的 `Source code (zip)` 是源码快照；直接运行请下载名称包含“Windows-x64”的成品附件。成品 ZIP 不加入源码 Git 历史，不影响将它上传到同一仓库的 Releases。
