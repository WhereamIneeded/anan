# Windows 桌面宠物安安

以用户的布偶猫「安安」为原型，制作独立运行、行为可定制的 Windows 桌面宠物。

**当前进度：交接资料与素材已整理，桌面程序尚未开发，没有可运行的安装包。** 原 ChatGPT Pets 中的安安已经制作并启用，本项目不修改它。

## 从公司电脑继续

```powershell
git clone https://github.com/WhereamIneeded/anan.git
cd anan
python scripts/校验交接资料.py
```

校验脚本只使用 Python 标准库；需要 Python 3.10 或更新版本。如果电脑尚未安装 Python，可以先阅读文档并由开发环境完成校验。未来桌宠成品会打包运行环境，使用者无需安装 Python。

先阅读以下文件，再开始实现：

1. [交接记录](docs/交接记录.md)：已完成与未完成、不可遗漏的约束。
2. [执行计划](docs/执行计划.md)：分阶段工作与验收标准。
3. [图片索引](docs/图片索引.md)：全部照片的用途与来源。
4. [素材与行为说明](docs/素材与行为说明.md)：现有图集、动作及新增动画设计。
5. [明日继续提示词](docs/明日继续提示词.md)：可以直接发给新电脑上的 Codex。

## 资料位置

- `资料/原始照片/`：原照片目录的全部 15 张图片，保留原文件名和原始字节；其中 12 张明确出现在用户会话，另 3 张补充保留。
- `资料/历史制作档案/成品与预览/`：现有 Pets 精灵图、基础形象、所有预览与提示合集。
- `资料/历史制作档案/源图与校验/`：全部历史源图、逐帧素材、布局参考、提示、图集描述及校验记录。
- `资料/来源清单.json`：每个来源文件与仓库文件的对应关系、大小、SHA-256。
- `资料/文件校验.json`：交接快照的全部文件清单，供脚本检查完整性。

历史制作档案已经完整展开，方便逐文件浏览，不依赖另一台电脑上的旧路径或原 ZIP 文件。历史记录中的绝对路径、服务端核验结果与时间仅作档案，不作为新项目的运行配置。

## 第一版目标

保留安安现有动作和外形，支持大小调整、拖动、单击跳跃、悬停不跳、随机猫咪日常动作、趴睡与仰卧睡及自然过渡。用相对路径加载随程序分发的动画资源，提供 Windows 构建脚本与 GitHub Actions 打包流程。

仓库按用户明确授权公开保存。普通开发、构建和使用无需连接 Pets 服务，也不需要图像生成服务的密钥。
