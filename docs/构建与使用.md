# 安安桌面版：构建与使用

## 直接使用

从 GitHub 仓库的 Releases 下载最新 Windows ZIP，解压整个文件夹，再双击 `安安.exe`。请保留相邻的运行依赖目录，不要只复制单个 EXE。

成品包含 Python、Qt 和全部动画资源，Windows x64 电脑无需安装 Python、无需图像服务密钥，解压后可离线使用。程序没有代码签名证书，Windows 可能显示未知发布者提示；这是尚未购买签名证书的分发限制。

## 交互

- 鼠标经过：安静注视，不跳跃，也不叫醒睡眠中的安安。
- 左键单击：跳跃；睡觉时先起身再跳。连续点击不会叠加无限跳跃。
- 按住左键拖动：移动安安，松开不会误触跳跃。
- 右键：调整大小、指定日常动作、趴睡、仰卧睡、叫醒、展示旧动作、隐藏和退出。
- 大小范围 100～400 逻辑像素，默认 220；数值包含动画画布的安全留白，系统缩放仍遵循 Windows DPI。
- 安静模式降低随机活动频率；偶尔散步默认关闭。
- 隐藏后从系统托盘右键选择显示，或单击托盘图标。
- 位置、大小与开关保存在 Windows 用户应用数据目录的「安安/安安桌面宠物」下，独立于源码和原 Pets。

没有鼠标操作时，安安会间隔一段时间做短动作，也可能趴睡或仰卧睡数分钟，醒来后经过起卧过渡恢复坐姿。第一版不自动读取 Codex 或其他应用的任务状态。

## 公司电脑还原最新版

```powershell
git clone https://github.com/WhereamIneeded/anan.git
cd anan
```

已有仓库先关闭正在运行的开发版，再执行 `git pull --ff-only`。如有自己的未提交修改，先提交或另存，再更新。

安装 Windows x64 Python 3.10 后，双击 `构建.cmd`，脚本会创建项目内虚拟环境、安装锁定依赖、运行测试并构建。产物保存在 `dist/安安-Windows-x64-v1.0.0.zip`。首次安装依赖需要网络。

动画成品已经入库，不需要运行素材制作脚本或再次生成图片。每份成品的 `版本.json` 记录实际源码提交，可与仓库最新提交对照。`SHA256SUMS.txt` 用于核对下载文件。

## 开发命令

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m anan_pet
.\.venv\Scripts\python.exe scripts/构建.py
```

运行资源在 `assets/`，程序在 `src/anan_pet/`；设计及实施记录在 `docs/`；新动作的内置 imagegen 提示、源图和预览在 `制作/新增动画/`；全部原照和既有素材仍在 `资料/`。

## 云端构建

GitHub Actions 在主分支更新或手动触发时，用干净 Windows 环境安装精确依赖、运行测试、构建并上传 ZIP。主分支构建成功后，以独立的构建标签创建新版 Release，并将其标为最新版；标签、源码和 ZIP 内的提交号对应。也可在 Actions 的对应运行记录下载构建产物。

公司电脑若不能安装开发工具，直接下载 Releases 的最新成品即可。运行环境、图片和行为逻辑都在成品中。
