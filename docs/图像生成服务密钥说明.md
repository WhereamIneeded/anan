# 图像生成服务密钥说明

说明日期：2026年10月31日。安安首版个性化生成已选择OpenAI官方图片接口；本文件解释用户需要准备什么，不表示真实照片生成已验收。

## 密钥是什么

API密钥是一串在OpenAI平台创建的秘密字符，程序凭它使用对应API项目的服务和额度。它不是ChatGPT登录密码，也不是GitHub登录凭据。

本项目中，只有“把猫咪照片生成新的动作图片”需要图像服务。默认安安的启动、日常动作、右键恢复默认，以及已经完成的自定义宠物在本机运行，都不需要API密钥。

## 如何准备

1. 打开[OpenAI平台的API密钥页面](https://platform.openai.com/api-keys)，登录自己的账户，在自己的API项目中创建密钥。
2. 在平台检查该项目的可用额度和模型权限；生成图片消耗API账户额度，创建密钥本身不代表已经有可用生成额度。
3. 保管好密钥。在本项目验证脚本提示时于普通终端隐藏输入，不把密钥发到聊天，也不粘贴进命令参数、源码、截图或Git。

当前验证脚本每次最多生成一张图片；先看待机基准，确认后才继续其他姿势。正常共7张，任务累计上限10次，超时或失败不会静默重复生成。实际收费以服务账户记录为准，不能把本机请求次数当作固定价格。

脚本优先读取当前进程的`OPENAI_API_KEY`；没有设置时在交互终端隐藏询问。当前阶段不要求手动修改系统环境变量，也不保存密钥。无法隐藏输入的终端会停止；无密钥不影响本机外观和默认恢复功能的开发与测试。

## 与ChatGPT订阅的关系

API项目的密钥和额度需要在API平台确认，不能仅凭已经登录ChatGPT就认定当前程序可以调用图片接口。符合官方资格的部分ChatGPT Pro、Business订阅可领取API额度，需要按平台流程激活并查看实际余额；不符合或余额用尽时，应以自己的API账户说明为准。

不要将“不能自动使用当前聊天登录状态”理解为必须再次购买某种ChatGPT订阅。用户可以先完成本机功能，之后再自行决定是否准备API服务。

## 官方依据

- [OpenAI开发者快速入门](https://developers.openai.com/api/docs/quickstart)：在平台创建API密钥并用于程序请求。
- [API认证说明](https://developers.openai.com/api/reference/overview)：密钥用于认证，应妥善保护。
- [ChatGPT订阅用户的API额度说明](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)：可领取资格、激活及余额规则，以账户实际状态为准。
