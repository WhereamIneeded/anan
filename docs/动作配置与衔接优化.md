用户同意参考成熟桌宠项目的设计，继续优化安安。本次保留 Python + PySide6，参考 [DyberPet 的动作和锚点配置](https://github.com/ChaozhongLiu/DyberPet/blob/main/docs/art_dev.md)及 [VPet 的开始、循环、结束阶段](https://github.com/LorisYounger/VPet/blob/main/VPet-Simulator.Core/Graph/GraphInfo.cs)，在本项目中独立实现配置与调度。

## 使用者能看到的变化

- 鼠标改变方向时，从最后显示的画面做 70 毫秒短过渡；低头姿势保留完整嘴和下巴。回正时继续保留完整头颈空间。
- 长时间拖动时持续播放走路，方向切换由控制器统一处理。松手清空未完成的动作，不误触跳跃。
- 重复要求同一种睡姿时继续睡，不会先起身再躺下。若尚未开始起身，再要求继续睡可以取消待执行的叫醒动作。
- 单击睡眠中的安安，只安排一次跳跃；先完整翻回、起身，再跳。拖动可取消这项等待。
- 鼠标停留时延后随机行为，移开后至少留出短暂安静时间。随机动作有权重、按时间计算的冷却和最近动作去重；短动作的比重高于长睡眠。
- 睡眠保持时间仍是 90～240 秒；起卧阶段使用已有真实姿势帧。启动与制作成品入口继续可双击使用。

## 动画与姿势配置

`assets/animations.json` 中的每段动画包括以下配置：

| 字段 | 含义 |
| --- | --- |
| `frames`、`durations` | 完整透明帧及各帧毫秒数 |
| `anchor` | 源画布上的落地对齐点；整张姿态平移至统一位置 |
| `loop` | 是否循环；走路、待机、注视、睡眠明确声明 |
| `blend_ms` | 相邻素材帧的短过渡 |
| `transition_ms` | 动作或注视方向切换的短过渡；起卧各阶段使用 0 |
| `stabilization` | 完整头部、眼部和静止身体区域，按动作配置 |

运行画布统一为 256×256，目标落地点为 `[123, 241]`。旧动作和新版挠耳使用既有落地点；日常及睡眠分镜按原制作脚本的 `[128, 241]` 对齐点平移，保留完整姿态及原有比例。坐姿眨眼和注视的稳定区域分别配置，播放器按前后两个姿态需要保留的最大区域处理过渡。

素材准备脚本更新帧路径和播放时长，保留已有循环和稳定区域；锚点按相应素材的生成规范记录，新版挠耳以实际前爪落地点为准。重新生成旧素材、新素材和新版挠耳均有覆盖，原始资料保留。

## 行为阶段配置

`assets/behaviors.json` 定义动作的中文名称、随机权重、冷却及阶段：

- `start`：进入阶段的动画顺序。
- `loop`、`hold_ms`：保持阶段及保持时间；对应动画必须允许循环。
- `end`：退出阶段，按进入阶段的反向顺序成对定义。

短动作只需定义 `start`，完整播放后恢复坐姿。睡眠定义完整三阶段，控制器根据当前完成的进入层级计算退出路线；共享姿态的退出路线必须一致，错误配置在启动时报告。

例如仰卧：趴下 → 翻身 → 仰卧保持 → 翻回 → 起身。刚开始趴下就收到点击，只需完成趴下、起身、跳跃；已经仰卧则必须先翻回。阶段判断由配置提供，不依赖动作名称中包含 `prone` 或 `supine`。

配置中的 `label` 同时用于右键菜单。随机动作禁止包含跳跃，权重为 0 的动作仍可手动播放。运行过程中不读取其他软件的工作状态。
