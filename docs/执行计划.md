# Windows 桌面宠物安安执行计划

## 目标与假设

制作可在两台 Windows 电脑间复现构建的独立桌面宠物。保留现有安安形象和全部动作，添加可配置大小、正确的鼠标交互及自然随机日常行为。

第一版暂按 Windows x64 设计，默认大小约 220 像素，建议可调范围 100～400 像素；这些是实现建议，需在高 DPI 屏幕和素材清晰度验收时确认。云端保存源码与成品动画，在 Windows 构建环境打包；成品在本机离线运行。首次拉代码和构建需要网络下载依赖。

技术上优先采用 Python + PySide6 + PyInstaller，减少自研窗口管理。精灵图与逐帧图直接随程序分发。避免添加账户系统、远程控制、联网遥测或自动开机启动等无关功能。

## 阶段一：恢复资料与建立项目

工作：
- 克隆 `anan`，运行交接校验，核对全部参考照片和现有图集。
- 阅读原始图集描述，固定帧裁取、透明边距与脚底基线。
- 核实可用 Python、Qt 和打包工具版本，建立虚拟环境并锁定已验证依赖。
- 新建应用入口、资源目录、最小启动脚本；加载资源使用项目相对路径与打包后的资源定位。

验收：全新路径可以安装依赖并启动，旧电脑的盘符和用户目录不参与运行；原始素材校验通过。

## 阶段二：桌面窗口与鼠标交互

工作：
- 透明、无边框、置顶窗口；默认显示安静坐姿。
- 大小滑块与预设；设置保存在 Windows 用户应用数据目录。
- 鼠标悬停时仅注视、眨眼或轻动耳朵，不触发跳跃。
- 记录按下点与移动距离；只有左键按下再松开且未达到拖动阈值才跳跃。
- 拖动时按方向复用左右走路，松手站稳，避免误触跳跃。
- 托盘和右键菜单提供显示、大小、打招呼、立即睡觉、叫醒、安静模式及退出。
- 支持多显示器、负坐标及不同 DPI；显示器变化后保证窗口能回到可见区域。

验收：悬停反复进入退出不跳；单击一次跳一次；拖动不跳；大小、位置重启后恢复；退出后没有残留进程。

## 阶段三：保留现有动作与建立行为状态机

工作：
- 复用安静陪伴、左右移动、招呼、跳跃、失落、等待、专心思考、仔细检查与 16 个注视方向。
- 对随机行为设置权重、冷却与最近动作去重，使用可控随机源便于测试。
- 长动作有进入、保持和退出阶段；不能在睡眠中直接切回坐姿。
- 点击具有明确优先级：清醒时跳跃；睡眠时先完成短暂醒来或起身，再跳跃。
- 鼠标经过不打断睡眠；拖动可中断当前动作，松手恢复稳定姿势。
- 避免随机调度产生自主跳跃，满足“单击才跳”。
- 自由散步作为可选功能，默认关闭；工作状态动画先提供手动演示入口。

验收：所有现有动作均可展示；随机序列不连续重复同一动作；无效切换、睡眠恢复及点击与拖动竞争有明确行为并通过测试。

## 阶段四：制作新增动作

优先级：
1. 挠耳：坐姿微歪头，后爪靠近耳侧轻挠，动作完成后恢复坐姿。
2. 趴睡：坐姿降低重心、收前爪、趴下、慢眨眼入睡；保持缓慢呼吸。
3. 仰卧睡：从躺姿翻身，白肚皮朝上，前爪放松蜷起，后腿自然摊开，头侧倒，蓬松棕尾保持完整；醒来翻回再起身。
4. 第一版完善：舔爪洗脸、打哈欠、伸懒腰、摆尾、轻微追尾巴；在前三项和过渡完成后制作，不挤占核心验收。

制作方式：
- 使用内置图像生成工具，读取可用 imagegen 技能，以现有基础形象锁定画风，以照片锁定花色、体型与睡姿。
- 每个动作分别生成、检查；保留提示、源图、透明帧、时间参数与预览。
- 新动作不受 Pets 固定 8×11 图集约束，按需要使用独立序列与单帧时长。
- 允许对生成图做裁切、去背景、对齐、缩放和拼接；不能用旋转或压扁旧坐姿代替新姿势。
- 所有最终素材入库，另一台电脑构建时不需要重新调用图像生成服务。

验收：新动作身份和画风一致；四肢、耳朵、尾巴完整，无杂色边、背景残留或脚底跳动；睡姿能对照用户原照；起卧、翻身与循环衔接自然。

## 阶段五：构建与云端交付

工作：
- 编写中文 README、启动说明、构建说明与一键构建入口，避免依赖全局修改 PowerShell 执行策略。
- 优先生成包含运行环境的 Windows 文件夹版 ZIP；用户解压后双击入口即可运行。
- 配置 GitHub Actions Windows x64 构建，上传 ZIP 构建产物；正式发布时再按需要建立版本 Release。
- 所有运行依赖显式声明并锁定；图集和新帧随包分发。
- 首先验证主分支或开发分支的干净检出能完成构建，再验证打包程序启动。

验收：干净 Windows 环境从仓库检出构建成功；包内无旧电脑路径；无 Python 的目标电脑可运行；从云端下载成品后核心交互和全部动画可用。

## 有效测试清单

- 状态机：点击跳跃、悬停不跳、拖动不触发点击、睡眠进入退出、随机去重和冷却。
- 素材：帧数、透明度、路径、资源完整性、稳定基线和边界。
- 窗口：缩放、高 DPI、多显示器、位置恢复、托盘退出。
- 分发：干净检出安装、自动构建、解压运行、离线使用。

状态机用不依赖 GUI 的单元测试验证；窗口使用 Qt 可行的自动检查与真实桌面手动验收。只报告实际完成的测试，不用“能启动”替代全部行为验收。

## 暂不包含

- 自动读取 Codex、其他应用或公司的工作状态。此类连接需要单独设计接口和用户授权。
- 声音、全屏追逐、自动开机启动、复杂物理引擎、天气系统和在线账户。
- 修改原 ChatGPT Pets 的图集、设置或应用安装文件。
