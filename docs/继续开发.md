## 已确认并落实的需求

1. 菜单召唤逗猫棒，跟随全局鼠标；安安在附近注视、伸爪，单击拍棒，手动收起。
2. 不定时长期索食；张嘴、抬爪、气泡和音符表达，先明显后低频，用户未响应时不自动结束。
3. 索食时单击喂一份默认冻干，或菜单选零食、冻干；投放、猫碗进食、食物减少、抬头舔嘴满足、撤碗。
4. 普通单击仍跳，拖动松手不误喂，睡眠先起身；菜单和大小框暂停，隐藏、拖动、切换等清理。
5. 声音偏好已经明确：**动画气泡为主，声音默认关闭**。不要重复追问；主动开启后每索食会话最多两次、间隔一分钟。
6. 摸摸、小球、纸箱仍是后续候选，没有实施，不在本轮自动扩展。

趣味互动原九组48张姿势和本轮体态统一38张姿势、原始分镜、中文提示、声音来源、准备脚本及真实窗口预览均已入库。旧附近关注、低头、去绿边和慢速挠耳继续保留；原ChatGPT Pets没有改动。
