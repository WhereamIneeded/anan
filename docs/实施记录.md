## 实施决定

- 使用现有独立克隆目录的开发分支实施；与原 Pets 项目隔离，不修改服务端 Pets。
- 纯 Python 行为控制器与 Qt 窗口分离；动画描述统一由动画加载器读取，避免接口重复。
- 默认宽度 220 逻辑像素，可调 100～400；窗口位置保存后按当前显示器可见区域恢复。
- 交接文件保持原始字节不变；新增运行资料另存。README 的当前进度只在实现验证后更新，历史交接校验清单保留原快照。
- 原照与历史素材不需要重新生成。新增动作使用内置 imagegen，成品入库后运行、构建均不需要图像服务。
- 成品以包含运行环境的 ZIP 分发；开发依赖精确锁定。GitHub Actions 使用 Windows runner 干净检出执行测试与打包，并提供成品下载。
