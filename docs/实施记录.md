依据：`docs/superpowers/plans/2026-10-22-安安桌面宠物.md`。用户于 2026 年 10 月 22 日要求完整实施，并将设计、资源、实现和构建同步到 GitHub，支持公司电脑还原最新版。

## 本次执行计划

1. 复核 330 个交接文件，锁定依赖，实现已有动作播放器。
2. 实现透明窗口、大小、拖动、点击手势与托盘菜单。
3. 实现可测试的随机行为、冷却、睡眠及起卧过渡。
4. 按原形象和原照生成挠耳、趴睡、仰卧睡及补充日常动作，保存提示、源图、最终帧与预览。
5. 完成 Windows 本地构建、无源码目录运行验证与云端构建配置。
6. 独立审查、修复、同步 GitHub，并从远端重新检出验证源码与资源。

## 实施决定

- 使用现有独立克隆目录的开发分支实施；与原 Pets 项目隔离，不修改服务端 Pets。
- 纯 Python 行为控制器与 Qt 窗口分离；动画描述统一由动画加载器读取，避免接口重复。
- 默认宽度 220 逻辑像素，可调 100～400；窗口位置保存后按当前显示器可见区域恢复。
- 交接文件保持原始字节不变；新增运行资料另存。README 的当前进度只在实现验证后更新，历史交接校验清单保留原快照。
- 原照与历史素材不需要重新生成。新增动作使用内置 imagegen，成品入库后运行、构建均不需要图像服务。
- 成品以包含运行环境的 ZIP 分发；开发依赖精确锁定。GitHub Actions 使用 Windows runner 干净检出执行测试与打包，并提供成品下载。

## 验收记录

- 开发前：原交接快照 329 文件、97,030,689 字节校验通过。
- 完成任务一至五：已有九状态及十六注视方向复用，20 段运行序列，新增24张透明原帧。
- 测试集中在 `tests/test_core.py` 和 `tests/test_visuals.py`，对应原计划的核心逻辑与 GUI 验收，减少重复的 Qt 初始化。
- 16 项测试通过；手势、设置、动画、长睡眠、随机去重、Qt交互、屏幕位置恢复和构建路径隔离均有检查。
- 图像工具实际输出四张1536×1024 RGBA分镜；角落透明，透明像素比例约38%～55%；仰卧轮廓已对照原照与预览检查。
- 独立审查发现并修复：屏幕几何变化后窗口可能留在屏幕外；新增回归测试先失败后通过。
- 发布采用每次构建独立标签，确保 Release 附件、自动源码包和提交相符。
- 本机初次打包时，PyInstaller 从 Codex 的 Poppler PATH 找到同名 ICU 库，导致 QtCore DLL 缺少导出。通过依赖表、实际加载路径与导出符号确认原因，隔离打包子进程 PATH 后修复；回归测试先失败后通过。
- 本地 Windows ZIP 已构建，约49MB；EXE 启动检查通过。解压到中文、空格目录，将 PATH 限制为 Windows 系统目录并移除外部 Python/Qt 环境后，EXE 仍可启动并自动退出。
- 原始 README、继续提示词和 gitignore 另存入资料目录，交接快照调整相应路径；原照和历史制作素材不变。
- 云端同步、干净 Windows 构建及 Release 下载验证在对应流程完成后补充。
- 从远端重新克隆后的干净安装发现：旧 pip 按 Windows GBK 读取中文依赖注释。依赖锁改为纯包名与版本的 ASCII 内容，一键入口显式启用 Python UTF-8 模式，避免公司电脑区域设置影响。

## 第一版的实际边界

没有自动读取外部任务状态。动画是固定关键帧，并不是连续骨骼模拟；躺姿和起卧已经有独立帧，后续仍可继续增加中间帧。没有在真实公司电脑上远程操作或测试真实多显示器硬件；本机 GUI、合成屏幕变化与独立运行检查不替代用户最终桌面体验验收。
