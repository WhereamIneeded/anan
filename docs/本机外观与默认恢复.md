# 本机外观与默认恢复

本阶段提供独立外观包的只读加载、当前选择持久化和右键“恢复默认安安”。恢复不需要网络、服务密钥或重新生成。安安内置素材与动作配置不会被自定义外观覆盖；恢复仅清除当前选择，保留最近的自定义结果以及大小、位置、安静模式、散步、自动索食和声音偏好。

右键“切换到自定义宠物”只在最近的完整外观包可用且当前未选中时启用。当前已经是默认安安时，“恢复默认安安”禁用。切换先验证全部图片并构建缓存，再保存选择；任何一步失败均保留当前外观并通过托盘提示。启动时自定义结果丢失或损坏会回到安安，保留自定义标识，提示原因；偏好写入失败也不会阻止默认安安启动。

切换会结束互动、关闭声音与逗猫监听、清除道具和气泡、取消拖动与动作队列、清除旧图片过渡并回到待机。工作状态仍是已有演示动作，没有新增与Codex任务状态的自动连接。

自定义宠物的注视方向变化也沿用原有短过渡，使用自己的完整帧进行混合；默认安安继续使用原身体稳定处理。

## 开发协议

以下为后续生成流程的内部接入约束，不是普通用户操作步骤。本阶段没有照片导入窗口，也没有生产外观包的完整产品流程。

外观包位于偏好文件同级的`宠物/<32位小写十六进制标识>/`，名称只用于显示，不参与路径计算。`宠物.json`使用中文字段：`格式版本`为整数1，`名称`为不超过32字的非空单行文字，`模板校验`为内置`animations.json`解析后按键排序、紧凑序列化所得UTF-8内容的SHA-256，`帧`为内置独立帧路径到包内PNG相对路径的映射。

当前模板有29个动作、155个独立帧槽位，映射必须恰好完整覆盖。重复播放引用复用同一槽位；不同槽位须使用独立文件。沿用内置时长、顺序、循环及过渡，不允许外观包定义脚本或任意行为。所有图片须是256×256的整幅透明PNG，有可见主体和实际透明像素；不进行包围盒重缩放、自定义图不去绿，也不混入安安的眼睛或身体稳定像素。绘制统一采用既有地面锚点。

清单上限512KiB，单帧上限2MiB。透明背景要求至少有完全透明像素；可见主体要求最大透明度值至少128，且至少64个像素的透明度值不低于32，避免整幅半透明背景或近乎不可见的空图。读取图片前先校验格式和尺寸；拒绝路径越界、绝对路径、备用数据流、符号链接越界、重复文件路径、损坏图片及不完整包。任意帧不合格均拒绝整包，不用安安补足缺失动作。

偏好新增`active_pet`和`custom_pet`，分别记录当前外观与最近自定义外观；为空表示未选中，旧偏好继续使用原默认值。恢复仅清除`active_pet`，不删除外观包。服务端ChatGPT Pets的安安不参与此流程。

## 可复现验证与边界

运行`python scripts/验证外观恢复.py`，使用临时偏好和真实Qt离屏窗口，逐个复制现有155帧并添加测试色调，导出`build/外观恢复预览/外观恢复浅深对照.png`与验证记录。预览明确标注“测试副本（非生成猫）”，检查默认全部帧像素恢复、源文件哈希不变和恢复后测试包保留。临时数据结束后自动清理，不访问用户实际偏好，不调用API。

自动化测试位于`tests/test_appearance.py`与`tests/test_appearance_window.py`。离屏验证不能替代真实Windows桌面人工验收；真实照片生成、服务密钥连通、生成结果完整性与自然度、照片导入交互和新版本EXE发布均未在本阶段完成。
