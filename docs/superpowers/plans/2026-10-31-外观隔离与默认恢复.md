# 本机外观隔离与默认安安恢复实施计划

> 使用superpowers:subagent-driven-development执行已确认设计中的本机阶段，测试驱动实现，先需求审查再质量审查。用户已要求继续，不重复请求开始许可。

**目标：** 自定义宠物与默认安安使用独立资源，支持本机选择、右键恢复默认及重启恢复；缺失或损坏的自定义资源回退安安。默认素材与动作配置逐字节不变。

**架构：** 新增外观加载边界，程序继续决定动作与玩法，宠物只提供完整姿势图片；默认使用原处理，自定义不使用安安去绿和头身蒙版。偏好只记录本机宠物标识，恢复默认只切换选择并保留自定义文件、大小、位置、静音等偏好。

**技术栈：** 当前Python与PySide6，不新增依赖、网络请求、密钥、在线账户或插件机制。

## 当前依据与范围

基线`551fe8a`，新隔离分支`codex/appearance-default-restore`。用户真实任务仍0请求，当前及用户环境未配置API密钥。依照总设计“缺少真实服务密钥时可继续做本机外观和替身测试”，先完成本机阶段；真实生成质量仍是完整导入与发布的验收门槛。

原OpenAI七姿势试验保持原任务与计数，目标仍为前方绿眼棕白狸花。不使用聊天凭据代替用户API密钥，不静默运行付费生成。

本阶段不加入照片导入窗口、不把7张代表姿势当完整宠物、不在界面提供开发配置文件流程，不发布新EXE。后续生成器可调用完整外观加载接口；测试使用既有帧的独立副本，不声称生成了新猫。

## 完整自定义资源协议

自定义目录位于偏好文件同级`宠物/<32位小写十六进制标识>/`；运行时就是现有应用数据目录下的独立宠物文件夹，不依赖旧盘符或EXE可写权限。名字只用于显示，不作为路径。

`宠物.json`结构如下，`帧`必须完整覆盖内置动画引用的155个独立相对路径；同一槽位的重复播放引用继续复用。

```json
{
  "格式版本": 1,
  "名称": "我的猫咪",
  "模板校验": "由当前内置动画配置的规范化JSON计算SHA256",
  "帧": {
    "frames/idle/00.png": "frames/000.png"
  }
}
```

上例仅展示结构，不是可加载的完整宠物，不能把只有一张图片的清单当成已完成。测试和后续生成器用当前内置配置完整枚举所有槽位，逐一填入相应文件。

- 动作标识、顺序、时长、循环和过渡均取程序内置配置，宠物清单不能改行为或执行代码。
- 清单限制大小、类型和名称长度，模板校验须匹配当前配置；按规范化JSON计算，避免换行或缩进改变造成误判。
- 所有相对路径解析后须位于自定义目录中；拒绝绝对路径、上级路径、符号链接越界和非PNG文件。不同独立姿势须对应不同文件路径。
- 图片读取前检查文件大小、格式和256×256画布，再解码；要求可见主体与真实透明通道，缺图、坏图或不完整155槽均拒绝，不能逐动作借用安安图片补齐。
- 自定义整帧已对齐共同画布，不采用安安专用去绿、眼睛坐标或头身蒙版。默认安安沿用原处理、落脚点和全部帧，不改`assets/`。

## 任务一：外观资源与偏好

红灯起点使用真实完整帧副本，下面代码可作为测试的独立基础；不以单张复制映射冒充完整槽位。

```python
import hashlib
import json
import shutil
from pathlib import Path

from PySide6.QtWidgets import QApplication

from anan_pet.animation import load_animations, resource_root
from anan_pet.appearance import load_appearance, template_signature


def test_complete_custom_bundle_keeps_builtin_resources(tmp_path):
    app = QApplication.instance() or QApplication([])
    assets = resource_root()
    before = {p.relative_to(assets).as_posix(): hashlib.sha256(p.read_bytes()).hexdigest()
              for p in assets.rglob('*') if p.is_file()}
    clips = load_animations(assets)
    originals = sorted({p for clip in clips.values() for p in clip.frames})
    target = tmp_path / ('a' * 32)
    (target / 'frames').mkdir(parents=True)
    mapping = {}
    for index, source in enumerate(originals):
        relative = f'frames/{index:03d}.png'
        shutil.copyfile(source, target / relative)
        mapping[source.relative_to(assets).as_posix()] = relative
    metadata = {'格式版本': 1, '名称': '自定义测试猫',
                '模板校验': template_signature(assets), '帧': mapping}
    (target / '宠物.json').write_text(json.dumps(metadata, ensure_ascii=False), encoding='utf-8')
    custom = load_appearance(assets, target)
    assert custom.name == '自定义测试猫'
    assert custom.pet_id == 'a' * 32
    assert set(custom.clips) == set(clips)
    assert all(custom.clips[key].durations == clip.durations for key, clip in clips.items())
    assert before == {p.relative_to(assets).as_posix(): hashlib.sha256(p.read_bytes()).hexdigest()
                      for p in assets.rglob('*') if p.is_file()}
```
