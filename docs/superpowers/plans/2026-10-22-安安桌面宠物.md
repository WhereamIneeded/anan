**目标：** 保留现有 Pets 安安，在独立 Windows 程序中实现可调大小、点击跳跃、拖动与自然猫咪待机，并可从仓库复现构建。

**架构：** PySide6 负责透明桌面窗口、鼠标事件、托盘及绘制；纯 Python 状态机负责行为和动画切换。动画作为静态资源随包分发，用户偏好保存在本机应用数据目录。

**技术栈：** Python、PySide6、PyInstaller、pytest、GitHub Actions Windows x64；开发时核实并锁定实际验证过的版本。

**需求依据：** `docs/执行计划.md`、`docs/素材与行为说明.md`、`docs/图片索引.md`、`docs/交接记录.md`。

## 全局约束

- 界面、文档、代码注释使用中文；原始资料保留字节不变。
- 原 ChatGPT Pets 安安不变，不修改插件或应用安装包。
- 悬停不能触发跳跃；左键单击才跳跃；拖动结束不触发单击。
- 大小建议 100～400 逻辑像素，默认 220；高 DPI 和资源清晰度验收后确定。
- 最终素材入库，构建和离线运行不需要图像生成密钥。
- 工作状态动作保留；第一版不自动读取 Codex 或其他应用状态。

## 重点验收条件

1. 拖动距离跨越系统阈值时，即使鼠标松开仍停在猫身上，也不能跳跃；由任务二测试。
2. 仰卧熟睡收到单击时，必须先起身再跳跃；由任务三测试。
3. 放大、缩小与显示器变化后，脚底基线稳定且桌宠仍在可见区域；由任务四测试。
4. 从包含中文、空格的新目录启动和打包后加载，资源均可找到；由任务一和任务六测试。
5. 起卧、翻身与随机循环切换时，不出现空白帧或身体瞬移；由任务三和任务五验收。

## 任务一：可运行的原始动作播放器

实现文件：`pyproject.toml`、`requirements.lock`、`src/anan_pet/__main__.py`、`src/anan_pet/animation.py`、`assets/animations.json`、`assets/frames/`；实际测试集中在 `tests/test_core.py` 和 `tests/test_visuals.py`。

接口：`load_animations(root: Path) -> dict[str, AnimationClip]`；`AnimationClip` 包含帧路径、逐帧毫秒数、循环起止位置。入口使用同一资源定位函数支持源码和打包目录。

- [x] 核对原始资料、最终图集及睡姿参考；历史记录为 329 个快照文件、15 张原照校验通过。
- [x] 实现九状态及十六注视方向的资源加载、逐帧播放和透明窗口。
- [x] 使用 `test_resource_counts_and_complete`、`test_resources_from_chinese_path` 检查帧数、资源完整性及中文空格路径。
- [x] 本轮重新校验 329 个快照文件及 15 张原照；Windows 全套 64 项测试通过，另有 4 项原生 Qt 检查通过。

## 任务二：鼠标手势和单击跳跃

实现文件：`src/anan_pet/window.py`；测试位于 `tests/test_core.py`、`tests/test_visuals.py`，使用任务一的动画接口。

接口：窗口使用 Qt 事件与系统拖动阈值，按下记录起点、移动判定拖动、松开仅对未拖动的左键发出点击事件。交互判定函数应可以在测试中使用合成坐标验证。

- [x] 实现悬停不跳、单击跳、拖动松手不跳；已有控制器和 Qt 合成交互检查。
- [x] 拖动复用左右移动动画；1.1.0 已加入长拖动循环检查。

## 任务三：日常行为和睡眠状态机

接口：`BehaviorController.handle(event: str, now_ms: int) -> None`、`BehaviorController.tick(now_ms: int) -> str` 返回当前动画标识；构造时注入随机源。事件使用 `click`、`drag_start`、`drag_end`、`sleep`、`wake`、`clip_finished`。

- [x] 实现可复现随机序列、动作去重与冷却，随机调度不选择跳跃。
- [x] 实现睡眠进入、保持、退出；点击先起身再跳，拖动取消待执行的跳跃。
