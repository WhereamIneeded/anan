> 执行要求：用户已于 2026 年 10 月 29 日明确“开始实现”。按已确认方案逐项执行；采用 `superpowers:subagent-driven-development` 的实现与独立审查流程；实际独立审查范围与最终主执行者复核边界记录在实施记录中。实现前先复现、写有效失败测试，实现后核对需求与代码质量。不要因断网或更换会话重新设计已经记录的需求。

**目标：** 交付可长期持续的逗猫棒和撒娇索食、单击喂食、猫碗进食闭环，保留安安现有桌面交互。

**架构：** 在现有 Qt 窗口、手势、行为和播放器之上增加纯 Python 趣味会话控制器。猫碗在既有画布内分层合成，窗口外的玩具和气泡使用不接受输入的装饰窗口。音频是默认关闭的附属通道，不决定状态流转。

**技术栈：** 现有 Python 3.10、PySide6、pytest、PyInstaller、Windows；短 WAV 优先使用标准库 `winsound`，不预先增加运行时依赖。

**依据：** [设计草案](../specs/2026-10-29-趣味互动设计.md)、[玩法调研](../../趣味玩法调研.md)、[续接入口](../../继续开发.md)。准备本计划时的主分支为 `0287dba`；已发布程序为 1.2.0，发布构建提交 `2366c13`。

## 任务 1：固定会话契约，先验证状态与计时

依赖：任务 0。文件：`play.py`、`assets/play.json`、`test_play_sessions.py`。

采用以下最小契约，测试与窗口共用，不再各自推断点击含义：

| 接口或字段 | 契约 |
|---|---|
| `load_play_config(root)` | 读取 `assets/play.json`，返回时间范围、气泡和资源映射；检查范围与资源引用 |
| `PlayController(config, rng)` | 注入可控随机源；初始无会话，不导入 Qt，不自行启动定时器 |
| `mode` | 只取 `none`、`begging`、`serving`、`eating`、`satisfied`、`teaser`、`teaser_swipe` |
| `session_id`、`origin` | 替换和取消会话时更新标识；索食继续到进食沿用同一会话；来源区分自动和手动，关闭自动索食不取消手动玩法 |
| `request(kind, now_ms, food='freeze_dried')` | `kind` 为 `beg`、`feed` 或 `teaser`；主动请求不无限排队；食物标识为 `snack` 或 `freeze_dried`，逗猫请求忽略食物参数 |
| `click(now_ms)` | 返回是否消费点击；无趣味会话返回假，窗口才执行原单击逻辑 |
| `tick(now_ms, auto_clock_running, session_running, can_auto_start)` | 独立控制自动索食时钟、当前会话暂停与安全触发点；忙碌时最多保留一个到期资格 |
| `set_target(position, center, width, now_ms)` | 只收逻辑坐标；计算棒尖附近反应，不读取全局点击或键盘 |
| `complete_clip(session_id, clip, now_ms)` | 只接受当前会话的当前阶段完成；重复、迟到的信号不改变状态 |
| `cancel(now_ms, reason)` | 清除会话视图与待执行阶段，返回普通模式；原因区分用户取消、拖动、隐藏和切换 |
| `view` | 只读绘制数据：模式、动作标识、方向、碗内级别、气泡、玩具位置；不包含 QWidget 或 QPixmap |

可先采用以下三个具体回归，接口均已在上表定义。这些是计划时固定的示例；实施中已建立对应回归，实际结果见实施记录：

```python
from random import Random

from anan_pet.animation import resource_root
from anan_pet.play import PlayController, load_play_config


def make_play():
    return PlayController(load_play_config(resource_root()), Random(0))


def test_begging_survives_twenty_minutes_without_response():
    play = make_play()
    play.request("beg", 0, "freeze_dried")
    # 一秒一步，不触发长时间跳变保护；不需要真实等待。
    for now in range(1000, 1_200_001, 1000):
        play.tick(now, auto_clock_running=False, session_running=True, can_auto_start=False)
    assert play.mode == "begging"


def test_repeated_clicks_are_consumed_and_cancel_restores_normal_click():
    play = make_play()
    play.request("beg", 0, "freeze_dried")
    assert play.click(1) is True
    assert play.mode == "serving"
    assert play.click(2) is True
    assert play.mode == "serving"
    play.cancel(3, "drag")
    assert play.mode == "none"
    assert play.click(4) is False


def test_previous_session_completion_cannot_change_current_play():
    play = make_play()
    play.request("feed", 0, "snack")
    old_session = play.session_id
    play.request("teaser", 1000)
    play.complete_clip(old_session, "eat_loop", 1100)
    assert play.mode == "teaser"
    assert play.session_id != old_session
```
