```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/校验交接资料.py
.\.venv\Scripts\python.exe -X utf8 -m pytest -q --basetemp build/pytest-20261027-完整复核
$env:QT_QPA_PLATFORM = 'windows'
.\.venv\Scripts\python.exe -X utf8 -m pytest tests/test_visuals.py -q --basetemp build/pytest-20261027-原生窗口
```

构建使用 `python -X utf8 scripts/构建.py`；将 `QT_QPA_PLATFORM` 设为 `offscreen`，并把 `PYINSTALLER_CONFIG_DIR`、`TEMP`、`TMP` 指向项目 `build/` 下的缓存和临时目录。构建日志保存在 `build/2026-10-27-构建日志.txt`。

独立验证将 ZIP 解压到 `build/独立运行验收/中文 空格目录-20261027/`，仅为子进程保留 Windows 系统 PATH，移除外部 Python、Qt 和虚拟环境变量，使用临时应用数据目录；分别以 `offscreen` 和 `windows` 平台运行 `安安.exe --smoke-test`。原生启动使用另一个没有源码的工作目录。完整测量保存在 `build/2026-10-27-独立运行验收.json`。这是本机环境隔离验证，没有实际卸载 Python，也没有替代另一台电脑验收。
