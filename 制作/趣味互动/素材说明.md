# 趣味互动素材

三张原始分镜由内置 image_gen 根据既有安安形象和原照生成，提示见 `生成提示.json`。`scripts/准备趣味互动素材.py` 提取九组共48个透明姿势，以统一倍率和落脚点制作运行帧，保留所有原件与旧动作配置。

`姿势对照.png` 与 `关键帧预览/` 保存素材的顺序和时长；这些是素材关键帧预览，不包含窗口过渡、猫碗、气泡或互动状态，不能当作完整程序已验收。集成后由实际窗口另导出完整玩法预览。

猫碗、食物与羽毛棒是同一准备脚本中的确定性简单绘图，运行PNG保存在 `assets/props/`。真实猫咪姿势来自图像生成，不是通过旋转、压缩或绘制旧猫咪冒充新动作。

可选猫叫的原件在 `音频原始/`，来源、CC0作者和转换参数见 `assets/audio/来源说明.md`；运行声音默认关闭。
